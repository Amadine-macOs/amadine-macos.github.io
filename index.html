How It Works

1. Start with Sheets

Create and organize artboards for your project—illustrations, UI, logos, or layouts.

2. Draw and Shape

Use Pen, Draw, or shapes like Ellipse and Star. Apply Width, Gradient, or Free Distortion for custom forms.

3. Refine and Edit

Select with Lasso or Eyedropper. Transform, slice with Scissors, erase cleanly. Add text on paths or shapes.

4. Export and Iterate

Finalize with precision tools like Offset Path. Export vectors ready for web, print, or apps.
